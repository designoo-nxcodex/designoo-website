Designing agents that stay under control

Daniel Reyes
Oct 2, 2026 · 8 min read

As agents move from demos into production systems, the hardest problems are no longer model quality. They are control, observability and trust.

An agent that can call tools, write to databases and send messages is effectively a privileged user. Treating it as a pure reasoning component is a category error.

Start with permissions, not prompts

The first design decision should be the set of tools and scopes the agent is allowed to use. We recommend a least-privilege model with explicit allow-lists per agent role.

Human-in-the-loop as a first-class path

Every production agent system we ship includes explicit escalation and approval gates as part of the normal control flow.

Trace everything

Full traces of reasoning, tool calls, intermediate state and final outputs are non-negotiable.

Closing

Agents are powerful precisely because they can act. The discipline of keeping them under control is what turns that power into something organizations can actually depend on.
